## Arborescence
- `src/index.js` — entrypoint stdio. Boot TRIVIAL : plus rien à amorcer (le daemon est lancé À LA DEMANDE par le premier profil HTTP). Shutdown idempotent (stdin close / SIGINT / SIGTERM → `stopAll`, qui ferme aussi les sockets du daemon = ref-count rendu). ⚠️ `try/catch` sur l'`await` de top-level OBLIGATOIRE.
- `src/manager.js` — config (`profiles.json`) + pool de backends + profil actif + hot-reload mtime. `_makeTransport()` : http ⇒ `acquerirProfil()` (daemon) + HttpTransport, sinon StdioTransport. 🛑 `_connexions` (profil→socket) **EST le ref-count** ; `_closeConnexion` = le rendre. ⚠️ `setActiveProfile` prend AVANT de lâcher (S4) ; `_reconcile` lâche AVANT de reprendre (redémarrage voulu). AUTO-RESTART (`_onBackendUnresponsive`, scope strict `sig==='unresponsive'`) + FORENSIQUE (`_logFreezeReport`).
- `src/auto-restart.js` — **PUR** : `shouldAutoRestart(recentTimestamps, now, {maxRestarts, windowMs})` — anti-boucle deterministe (< maxRestarts DANS la fenetre glissante). Defauts `DEFAULT_MAX_RESTARTS=3`/`DEFAULT_WINDOW_MS=300000`. Zero I/O, zero horloge lue (now=parametre).
- `src/freeze-report.js` — **PUR** : `formatFreezeReport(facts)` — rapport forensique de gel (profil, serveur pid/vivant/port, **discriminant Chrome MORT (0) vs FIGE (>0)**, requetes en vol + age, pings rates). Fonction TOTALE (jamais throw). Aucune I/O ni horloge (faits passes par le manager). Le « bloc de logs » scelle : la prochaine occurrence d'un bug tordu devient diagnosticable.
- `src/budget.js` — **PUR** : **SOURCE UNIQUE de tous les délais**. Famille CLIENT (`clientBudgetMs(env)` hérité de `MCP_TIMEOUT` — surface officielle Claude Code — défaut **mesuré** 30000 ; `handshakeBudgetMs` = `HANDSHAKE_RATIO` 0.8 ; **`handshakeFitsBudget` = LE GATE** fails-closed) et famille BACKEND (`READY_TIMEOUT_MS` 90 s ancré sur `systemd DefaultTimeoutStartSec`, `READY_POLL_MS`, `PROBE_TIMEOUT_MS`, `CONFIG_WATCH_INTERVAL_MS`, `ALERT_TIMEOUT_MS`). ⚠️ Ne dérive QUE ce qui a un lien causal réel : le temps de boot d'un backend n'est PAS fonction du budget client (faux couplage interdit). ⚠️ `LOCK_*`/`SERVER_TTL_MS`/`HEARTBEAT_MS`/`SPAWN_ATTEMPTS` SUPPRIMÉS avec le superviseur — les réintroduire signalerait le retour d'un registre.
- `src/deadline.js` — **PUR** : `withDeadline(promise, ms, {delay})` — course promesse/échéance, `delay` INJECTÉ (déterministe, zéro faux timer). Repli UNIQUE : échéance **et** rejet donnent `{ok:false}`. ⚠️ Absorbe le rejet TARDIF de la promesse perdante (sinon `unhandledRejection` qui tue le proxy longtemps après). Point UNIQUE de cette course — ne JAMAIS ré-écrire un `setTimeout` de course ailleurs.
- `src/error-detail.js` — **PUR** : `describeError(err)` — rend une erreur d'I/O DIAGNOSTICABLE (message + `code`/`syscall`/`errno`/`address`/`port`, ordre stable, fonction TOTALE, jamais vide). Ne du 01/08 : `err.message` VIDE = incident non diagnosticable. `err.message` seul est INTERDIT dans tout chemin de log d'I/O.
- `src/channel-name.js` — **PUR** : nom du canal du DAEMON UNIQUE (`daemonChannelName`), dérivé du seul segment UTILISATEUR (espace de noms des named pipes = GLOBAL machine). Percent-encoding REVERSIBLE, jamais un hash (collision = 2 comptes qui partagent un daemon). POSIX : `$XDG_RUNTIME_DIR` avant `/tmp` (systemd purge /tmp a 10 j). Trop long ⇒ erreur, jamais de troncature. ⚠️ `channelName(profil)` (canal PAR PROFIL) SUPPRIMÉ le 02/08 : code mort depuis le daemon unique — ne pas le réintroduire.
- `src/backend.js` — **AGNOSTIQUE au transport** : reçoit un transport injecté (start/send/close + events message/exit/error). Toute la logique PROTOCOLAIRE ici (handshake, mapping ids, forward bidir). `stop()` = transport.close(). **WATCHDOG de liveness** (`_startWatchdog`/`_pingOnce`) : tant qu'une requête est en vol, ping le backend ; K pings sans réponse ⇒ `_onExit('unresponsive')` ⇒ `-32000`. Délais injectables `options.ping{Interval,Timeout}Ms`/`maxMissedPings`. **FORENSIQUE** : `_forwardMeta` (backendId→{tool,startedAt}) + `inflightSummary()` (requetes en vol + age) ; sur gel detecte, emet `'freeze'` (snapshot AVANT `_onExit` qui vide les maps) pour que le manager ecrive le rapport.
- `src/stdio-transport.js` — **I/O** transport stdio : spawn child MCP (ndjson), `close()` = **treeKill** (anti-leak P0). `shell:true` UNIQUEMENT commande bare ; `detached` POSIX.
