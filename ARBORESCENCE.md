## Arborescence
- `src/index.js` — entrypoint stdio. Boot : `manager.bootSupervision()` (boot-reap + reaper si mode http) → sert. Shutdown async idempotent (stdin close / SIGINT / SIGTERM → `stopSupervision` (désenregistre mes heartbeats) + `stopAll`). **PLUS de lock/boot-sweep global** (retirés — cassaient le multi-agent).
- `src/manager.js` — config (`profiles.json`) + pool de backends + profil actif + hot-reload mtime. `_isHttp()` (flag `http` profil/global), `_makeTransport()` (http: ensureServer+registerClient+HttpTransport ; sinon StdioTransport), `bootSupervision`/`stopSupervision`, `restartProfile`, `stopAll`. Options injectables `options.watchdog`/`options.autoRestart` au constructeur (defauts prod si omis). **FORENSIQUE** : `_logFreezeReport` cablé sur `backend.on('freeze',...)` — collecte l'etat REEL au gel (pid serveur+vivant via superviseur, **nb de Chrome pour le udd** = mort/fige, requetes en vol) et log le rapport `formatFreezeReport` (PUR). Best-effort (ne throw jamais), OBSERVATION seule (ne decide rien).
- `src/auto-restart.js` — **PUR** : `shouldAutoRestart(recentTimestamps, now, {maxRestarts, windowMs})` — anti-boucle deterministe (< maxRestarts DANS la fenetre glissante). Defauts `DEFAULT_MAX_RESTARTS=3`/`DEFAULT_WINDOW_MS=300000`. Zero I/O, zero horloge lue (now=parametre).
- `src/freeze-report.js` — **PUR** : `formatFreezeReport(facts)` — rapport forensique de gel (profil, serveur pid/vivant/port, **discriminant Chrome MORT (0) vs FIGE (>0)**, requetes en vol + age, pings rates). - `src/budget.js` — **PUR** : **SOURCE UNIQUE de tous les délais**.
